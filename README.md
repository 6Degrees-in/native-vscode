# Native VS Code

Platform-native VS Code configurations for macOS and Windows, focused on refined visuals, thoughtful ergonomics, and a clean, distraction-free coding environment.

## Platforms

- macOS — available
- Windows — planned

## Installation

### macOS

Copy the contents of `macos/settings.json` into your VS Code User `settings.json`.

### Windows

Windows configuration will be added in a future release.

## Releases

Configuration versions are distributed through GitHub Releases.

- v1.0.0 — Initial configuration
- v2.0.0 — Refined configuration
- v3.0.0 — Advanced macOS configuration
